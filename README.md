> **"Should I text my ex?" "Is it weird that I eat pizza with a fork?" "Am I the drama? 🎭"**

Stop overthinking alone. Welcome to **Judge Me**, the ultimate anonymous playground where your real-life dilemmas meet the unfiltered honesty of the internet. Whether it’s a moral quandary, a social blunder, or just a silly debate, post it anonymously and let the world pass the final verdict.

---

## ✨ Features

- **🎭 Pure Anonymity:** No accounts, no profiles, no judgment of *you*—just your situation.
- **⚡ Real-time Verdicts:** Watch the scales tip in real-time with animated vote bars.
- **🌈 Immersive UI:** A modern, glassmorphic design featuring playful gradients and smooth micro-interactions.
- **📱 Mobile First:** Perfectly optimized for judging on the go.
- **🔄 Fresh Tea:** A dynamic feed where the latest dramas always sit at the top.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Custom pastel themes)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **API:** Native Fetch with Environment-based configuration
- **Icons:** [Lucide React](https://lucide.dev/) & Tasteful Emojis

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- pnpm / npm / yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/judge-me-app.git
   cd judge-me-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env.local` file in the root:
   ```env
   NEXT_PUBLIC_API_BASE=your_api_endpoint_here
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to start judging!

## 🎨 Design Philosophy

Judge Me is built to feel **alive and playful**. We avoid plain white backgrounds in favor of soft, uniquely-hued pastel gradients for every card. Every interaction—from a button click to a page scroll—is accompanied by subtle, spring-based animations to make the experience feel snappy and expressive.
